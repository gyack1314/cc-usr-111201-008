# 持续结果资料

计划配置可用精确分数串。stream_id和sequence共同决定业务身份；event_id是来源追踪元数据，不取代此二元身份。相同业务身份的outcome冲突拒绝，但相同结果的重传即使event_id不同也不能推进第二次。sequence从1开始。sources按交付顺序排列，流内缺口暂存，连续前缀之外事件不计入当前比例。

每条备择财富的log值从零开始，e为mixture的财富加权和，而非每步混合因子的乘积。边界比较需要避免log舍入漏掉恰等阈值，exact-threshold含两个成功，e=4恰等1/alpha。报告可使用log_e和十进制科学计数值表示极大极小数，不输出非法JSON Inf/NaN。计划摘要覆盖全部stream配置和全局预算，追加事件不改变计划。小路径null校验以每stream独立Bernoulli(p0)的路径概率枚举；此示例不替代一般条件null保证。

domain只去除同结果重传并统计已收到数量，无e值、前缀处理或报警持久化。
