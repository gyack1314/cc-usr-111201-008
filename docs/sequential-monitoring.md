# 序贯e值监测（eseq）

面向试运营值班的只读序贯监测：数据到来时更新证据，随时可以查看，且任何时刻都能说明采用了什么假设和误报预算。模块只读取已确认的0/1结果，不控制现场设备；报警回执只是本地日志记录，不发送真实消息。字段与数学口径同时见[资料约定](data-contract.md)。

## 统计模型与假设

- 每条流预先登记基线 `p0`（0<p0<1）。原假设 H0：在已知该流历史结果的条件下，每一步异常(1)的条件概率不超过 p0。**不假设各步相互独立**。
- 配置预先给定若干备择 `q_j`（p0<q_j<1）与和为1的正混合权重 `w_j`，启动前冻结。
- 第 t 步的 e 值：`E_t = Σ_j w_j · Π_{s≤t} LR_j(x_s)`，其中 `LR_j(1)=q_j/p0`，`LR_j(0)=(1-q_j)/(1-p0)`。**先在每个 j 内部连乘，再按权重混合**，不是每步混合因子的连乘。空前缀 `E_0=1`。更新在 log 域进行。

## 为什么可以随时查看（联合误报控制）

- 在 H0 下，每个 j 的财富过程 `W_j,t=Π_{s≤t}LR_j(x_s)` 是非负超鞅：若第 t 步的条件异常概率 `p_t≤p0`，则单步条件期望因子 `p_t·q_j/p0+(1-p_t)·(1-q_j)/(1-p0)` 关于 `p_t` 递增且在 `p0` 处等于 1，故不超过 1。
- 权重和为1的混合仍是非负超鞅，且初值为1。由 Ville 不等式：`P(存在 t 使 E_t ≥ 1/α_s) ≤ α_s`。
- 各流预算 `α_s` 启动前冻结且 `Σα_s ≤ global_alpha`。由并合界（union bound）：`P(任一流任一时刻误报) ≤ Σα_s ≤ global_alpha`，不要求流间独立。
- 因此值班组每天任意次查看、反复检验都不消耗额外预算——这正是"序贯"的含义，也是它替代固定样本检验的原因。

## 报警语义

- 每条流在 e 首次达到 `e ≥ 1/α_s`（**恰等计入**）时报警并记录回执，同时记录首次越界位置 t 与历来最大 e。
- 报警后继续记录，证据不重置、不另领预算；同一计划内同一流只首次报警一次。
- **e 值不是概率，也不是当前异常率**；当前比例 `k/n` 在报告中以 `proportion` 字段单独列出，且只统计已处理的连续前缀。

## 计划管理（不得看完数据再调阈值）

- 计划 = 全部流配置 + 全局预算，以规范化配置的 SHA-256 作为 `plan_id`，开启后不可修改；事件不属于计划身份。
- 新增流或修改 p0/q/alpha 必须开启明确的新计划；旧计划与其日志完整保留（`plans` 命令可见全部计划）。
- 模块没有"修改阈值"的接口：看完数据再调阈值然后声称原误报保证，在这里无从表达。

## 事件顺序、幂等与持久化

- 事件身份 = `(stream_id, sequence)`，sequence 从1开始严格递增；`event_id` 仅为来源追踪元数据。
- 允许跨流乱序交付；流内缺口暂存，只处理连续前缀，缺口之外的事件不计入当前比例与 e 值。
- 同内容重传幂等（即使 event_id 不同也不推进第二次，且不重复写日志）；同身份不同结果拒绝（`EventConflict`），不写入日志。
- `journal.jsonl` 是唯一事实来源：受理事件按到达顺序追加并 fsync，报警回执紧随其后。进程退出后重放日志重建完全一致的状态；回执由事件流确定性重推导并逐条校验，缺失补写、不符即抛 `CorruptionError`。

## 数值口径

- log 域更新避免长链下溢/上溢：数千步连乘在 float64 下会下溢为 0 或上溢为 inf，log 域保持有限（`demo` 场景一，并与高精度 Decimal 交叉核对）。
- 边界判定：`|log_e − log(1/α_s)|` 落入相对 1e-9 带内时改用精确分数（Fraction）判定，恰等阈值不漏报（`demo` 场景二；`data/exact-threshold.json`）。
- 报告中 e 以 `log_e` 与十进制科学计数字符串表示，不输出非法 JSON 的 Inf/NaN。

## 审计与枚举校验

- `audit`：由日志中的原始事件独立重算每条流的全部前缀（不复用监测器的增量状态），与当前状态逐项比对。
- `enumcheck`：小样本枚举全部 2^n 条 Bernoulli(p0) 路径，用精确分数核算越界概率并核对不超过该流 α_s；各流 α_s 之和不超过全局 α。此为独立同分布下的示例性校验，**不替代**一般条件 null 下的超鞅保证。

## 命令

```sh
python -m eseq.cli run data/normal.json                  # 内存中受理事件并打印每步e值
python -m eseq.cli run data/normal.json --root /tmp/mon  # 持久化：开启计划、写日志与报警回执
python -m eseq.cli plans /tmp/mon                        # 列出全部计划（旧计划保留）
python -m eseq.cli status /tmp/mon <plan_id>             # 假设、预算、证据、当前比例
python -m eseq.cli audit /tmp/mon <plan_id>              # 独立重算全部前缀并比对
python -m eseq.cli enumcheck data/normal.json --n 10     # 枚举Bernoulli路径核算越界概率
python -m eseq.cli demo                                  # 长链下溢/恰等阈值/缺口补齐/重启
```
